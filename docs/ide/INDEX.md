- [PLAN_REDISENO_ESTUDIO_IDE_2026-08-22.md](PLAN_REDISENO_ESTUDIO_IDE_2026-08-22.md) — rediseño

- [AUDITORIA_ESTUDIO_PROFUNDA_2026-08-19.md](AUDITORIA_ESTUDIO_PROFUNDA_2026-08-19.md) — bugs

  atajos de teclado y el motor de búsqueda de Estudio.
