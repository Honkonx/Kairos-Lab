# Kairos Lab

Public artifacts and (eventually) adapted documentation for [Kairos](https://github.com/Honkonx/kairos-dev) —
a native Android APK (fork of termux-app) that runs local AI services (Ollama, llama.cpp, n8n,
OpenClaw, code agents) on-device via a native Kotlin/Java UI, no terminal commands required for
day-to-day use.

This repo currently hosts prebuilt release assets (e.g. cross-compiled Python wheels for
aarch64-linux-android that avoid compiling native code on-device). Full public code + adapted
docs are planned for a future release.
