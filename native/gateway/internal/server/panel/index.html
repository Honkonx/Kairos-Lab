Pantalla

Espejo y control táctil real de la pantalla del teléfono (ver docs/homelab/ESPEJO_PANTALLA_FUNCIONAL_2026-10-13.md) usando un servidor propio adaptado de scrcpy (Apache-2.0, con crédito — ver docs/CREDITOS.md), sin ADB ni red: todo por un socket local del propio dispositivo. "Conectar" abre el relay del gateway (/v1/screen/ws); si no hay ninguna sesión de pantalla arrancada todavía (botón "Iniciar" más abajo), el relay responde con error hasta que se arranque una — arrancar el gateway con KAIROS_GATEWAY_SCREEN_STUB=1 deja probar el relay completo (websocket, control, reconexión) con datos simulados, sin tocar la pantalla real. Exige nivel total (con la casilla de responsabilidad marcada): controlar la pantalla es controlar el dispositivo entero.

Transporte por USB (además de la red local)

Este panel ya habla por un WebSocket normal (/v1/screen/ws sobre el puerto 8973 del gateway) — por USB no hace falta nada especial del lado de Kairos: en la PC, con el cable conectado y la depuración por USB habilitada, adb forward tcp:8973 tcp:8973 (o adb reverse si el sentido fuera al revés) deja usar http://127.0.0.1:8973/ en la PC como si fuera la red local — mismo token, mismas acciones, sin Wi-Fi. No se implementó nada nuevo para esto: es el mismo mecanismo de cualquier app que hable HTTP/WebSocket por el gateway, solo reenviado por el cable en vez de por la red — ver docs/homelab/ESPEJO_PANTALLA_FUNCIONAL_2026-10-13.md para el detalle completo (incluye lo que SÍ falta confirmar en un dispositivo real).
